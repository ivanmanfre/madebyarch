How this page was built
  • All figures come from the YouTube Data API v3 (search.list, videos.list, channels.list); no HTML scraping, no authenticated session.
  • YouTube's public all-time “~N results” estimate is not available via the API and reading it requires a public-page read, so this page carries no all-time volume number.
  • Per-window result counts are the API's totalResults estimate, which fluctuates between reads; treat as order of magnitude.
  • View counts drift upward; all figures are a snapshot taken on the read date.
  • Paid-promotion status uses the API's paidProductPlacementDetails flag, which was returned for every video in the sample. The watch-page 'Includes paid promotion' overlay was not checked by hand.
  • Ten queries, page one of each, de-duplicated to 430 videos. The sample is a floor and TrainStation 3 content outside it sits outside the claim boundary.
  • Videos were classified by title and channel into ten labels declared before either pass ran. A second reviewer who never saw the first pass re-tagged a fixed 20% sample of 87 videos and disagreed on none of them.
  • The query “trainstation 3” collides with real-world railway, model-railway, language-lesson and unrelated-game content, so the off-topic share below is a property of the search term as much as of the game.
  • The game's own channel was confirmed by reading the @trainstation-games channel page, which names TrainStation 2 and TrainStation 3 and links to Pixel Federation install pages. Ownership beyond what that page states is not verifiable through the API.
  • Reach multiple divides a channel's biggest video in this sample by its subscriber count. The sample catches whichever upload fell inside a 30-day window, so a low multiple can describe a routine upload on a large back catalogue.

What this does not contain: watch time, audience demographics, CPM or rate-card estimates, sentiment scores, or YouTube’s all-time results figure, which the API does not expose and which we omit instead of estimating. View counts drift upward; every number is a snapshot from 27 August 2026. The full claim-to-URL list behind every figure is available on request.
