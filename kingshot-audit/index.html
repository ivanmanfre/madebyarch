How this page was built
  • All figures come from the YouTube Data API v3 (search.list, videos.list, channels.list). No HTML scraping, no authenticated session.
  • YouTube’s public all-time “~N results” figure is not exposed by the API; the all-time volume claim is omitted for that reason.
  • Per-window result counts are the API's totalResults estimate, which fluctuates between reads; treat as order of magnitude.
  • View counts drift upward; all figures are a snapshot taken on the read date.
  • Paid-promotion status uses the API’s paidProductPlacementDetails flag where available; the watch-page 'Includes paid promotion' overlay was not checked for this page.
  • Sample claims describe the 344-video sample only; Kingshot content outside the sample is outside the claim boundary.
  • The first channel-search hit for the game's name (Kingshot Mühendisi, a fan channel) is not an official channel; no active official Kingshot channel exists on YouTube as of the read date. Ownership of the empty @kingshotofficial channel cannot be verified via the API.

What this deliberately does not contain: watch time, audience demographics, CPM or rate-card estimates, sentiment scored by a model, or YouTube’s all-time results figure, which the API does not expose and which we omit instead of estimating. View counts drift upward; every number is a snapshot from 14 August 2026. The full claim-to-URL list ships alongside this page as sources.json.
